# Python Sales Calculations

## Project Overview

This project combines three Python programs into one application.

### Features

1. Sales Commission Calculator
   - Calculates sales commissions for sellers.
   - Displays sales totals and commission amounts.

2. Stock Movement Management
   - Displays available products.
   - Records stock entries and exits.
   - Updates final product quantities.

3. Interest Calculator
   - Calculates overdue days.
   - Calculates interest on outstanding amounts.
   - Displays the total amount due.

## Technologies Used

- Python
- JSON
- VS Code

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

   python main.py
